# Changelog — widget_basic

One entry per released version (newest first).

## [1.0.1] - 2026-11-05

### Changed
- Gauges and numeric indicators fit their text with fewer repeated font measurements; numeric-indicator captions update their fit when resized or when their font changes.

## [1.0.0] - 2026-10-15

### Added
- Gauge: arc or bar, with minimum, maximum, unit, decimals and a red zone from a configurable value.
- Numeric indicator: one number in large type with an optional label, unit and decimals.
- Traffic light: green below one threshold, red from another, amber in between.
- Value table: one row per wired series, with configurable decimals.
